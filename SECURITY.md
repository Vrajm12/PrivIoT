# Security Policy

## Supported Versions

PrivIoT Shield actively maintains security fixes on the latest `main` branch.

| Version / Branch | Supported |
| :--- | :--- |
| `main` (latest) | Yes |
| Older snapshots | No |

## Reporting a Vulnerability

Please **do not** report undisclosed security vulnerabilities through public GitHub issues.

Instead, report findings privately via:
- **GitHub Private Vulnerability Reporting:** Use the **Security -> Report a vulnerability** tab on this repository, or
- **Direct Contact:** Reach out via the contact channels listed at [veerajmatnale.me](https://veerajmatnale.me).

### What to Include
1. Affected module, endpoint, or scanner component.
2. Minimal reproduction steps or proof-of-concept payload.
3. Potential security impact (e.g., command injection, SSRF, credential exposure, parser DoS).

We acknowledge valid reports promptly and coordinate fixes before public disclosure.
